# GPROXY documentation

The source of <https://gproxy.leenhawk.com>, built and hosted by
[Mintlify](https://mintlify.com) from this repository. It is also the `docs/`
submodule of [LeenHawk/gproxy](https://github.com/LeenHawk/gproxy), and is
mirrored to GitLab, CNB and git.lin.pub.

## Layout

- `docs.json`: site settings, navigation for the four languages
  (English at the root, `zh-cn/`, `zh-tw/`, `ru/`) and redirects.
- Pages are `.mdx` files whose path is their URL. Keep every language's tree
  aligned with the English one.
- `snippets/`: React components (`download-page.jsx`, `video-tutorial.jsx`,
  `components.css`) and `snippets/generated/`, the rendered reference tables.
- `generated/`: the OpenAPI document, configuration JSON Schema and defaults,
  and the channel catalogue, exported from gproxy's Rust code. The HTTP API
  pages are generated by Mintlify from `generated/openapi.json`.
- `tutorials/<topic>/{en,zh,ru}.mp4`: subtitles are burned in; `ru.mp4` is the
  English video with Russian subtitles.
- `notifications.json`: the announcement feed for GPROXY releases up to
  v4.1.14, which read it from this site. It is written by gproxy's
  Notifications workflow; `/notifications.json.sig` redirects to the signature
  published with it, so **do not edit this file by hand**: a copy that differs
  from the published feed fails verification. Newer releases read the feed from
  the `notifications` release on GitHub, CNB or GitLab.
- `install.sh`, `install.ps1`: `/install.sh` and `/install.ps1` redirect to
  their raw files on CNB (Mintlify does not serve these extensions).

## Working on it

```sh
pnpm install --frozen-lockfile
pnpm dev     # local preview
pnpm check   # notifications.json, mint validate, mint broken-links
```

## Reference

gproxy's CI runs `scripts/generate-reference.mjs` on every push of its `main`
or `dev` and commits the result to the branch of the same name here: the JSON in
`generated/` and the tables `scripts/render-reference.mjs` renders from it into
`snippets/generated/`. To preview an unreleased Rust change, run it from a
gproxy checkout (the parent directory when this repository is its submodule,
or `GPROXY_ROOT`):

```sh
pnpm generate:reference
```

It runs the `gproxy-host-axum` `export-docs` example with the `documentation`
feature and every channel in the SDK's `channels` feature group; it does not
start a gateway or contact upstream providers. Descriptions come from Rust doc
comments and stay in English in every language; table labels are localized in
`scripts/reference-labels.mjs`.
