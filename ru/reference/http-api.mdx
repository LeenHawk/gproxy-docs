title: "Справочник HTTP API"
description: "Полные схемы запросов, ответов и событий API пересылки, управления, личного кабинета и OAuth."
---

Этот справочник описывает каждую конечную точку HTTP: параметры, тело запроса,
ответы и используемые структуры данных. Он генерируется из типов протокола
Rust, DTO управления и объявлений маршрутов хоста; схемы запросов и ответов
следуют их определениям Serde. У каждой конечной точки есть своя страница в
разделе **HTTP API** боковой панели, сгруппированная по Forwarding,
Codex provider, Management, Portal, OAuth и System.

Общие пути пересылки выбирают протокол по заголовкам запроса, а
`stream: true` включает потоковую операцию. Схемы SSE описывают одно
декодированное событие, схемы WebSocket — сообщения после переключения
протокола. Двоичные и multipart-данные сохраняют свои типы содержимого.

Пути пересылки работают и с префиксом провайдера или пространства имён, а пути,
специфичные для Codex, требуют имени провайдера Codex. Точки монтирования,
аутентификация и области управления описаны в разделе
[Маршрутизация и конечные точки](/ru/reference/routing-table).

Полная спецификация доступна в виде [OpenAPI JSON](/generated/openapi.json) —
её можно импортировать в Postman, Insomnia или генератор кода.
