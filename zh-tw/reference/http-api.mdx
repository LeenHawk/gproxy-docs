本參考說明每個 HTTP 端點的參數、請求主體、回應及其引用的資料結構，內容從 Rust 協定型別、管理 DTO 和宿主路由宣告產生，請求與回應結構遵循各自的 Serde 定義。每個端點在側欄「HTTP API」分組下都有獨立的頁面，按 Forwarding、Codex provider、Management、Portal、OAuth 和 System 分類。

共用的轉發路徑根據請求標頭選擇協定，`stream: true` 切換為串流操作。SSE 結構描述解碼後的單一事件，WebSocket 結構描述升級連線後收發的訊息；二進位與 multipart 承載內容保留各自的內容型別。

轉發路徑也可以加上供應商或命名空間前綴，Codex 專用路徑需要使用 Codex 供應商的名稱。掛載點、驗證和管理權限範圍見[路由與端點](/zh-tw/reference/routing-table)。

完整規格可下載 [OpenAPI JSON](/generated/openapi.json)，匯入 Postman、Insomnia 或程式碼產生工具使用。
