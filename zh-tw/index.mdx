## 常用功能

<Columns cols={2}>
  <Card title="管理上游帳戶" icon="gear">
  在一個控制台管理 API Key、OAuth 和 Cookie 憑證，檢視健康狀態和上游額度。
</Card>
  <Card title="配置模型路由" icon="shuffle">
  為用戶端設定固定的模型名，按權重分配請求，並配置備用供應商。
</Card>
  <Card title="連線不同協議" icon="puzzle-piece">
  支援 OpenAI、Claude 和 Gemini API 格式及串流回應，具體操作取決於渠道和上游能力。
</Card>
  <Card title="檢視用量與費用" icon="file-lines">
  管理使用者和金鑰的訪問權限與費用預算，檢視請求記錄和計費明細。
</Card>
</Columns>
