GPROXY 是在你的裝置上執行的開源 AI API 閘道。發布者不提供 AI 帳號、模型訂閱或託管的閘道帳號。本說明適用於 GPROXY 應用程式，不取代你自行接入的第三方服務的隱私權政策。

## 應用程式處理的資訊

設定和使用閘道時，應用程式會處理供應商帳號及 API 憑證、閘道使用者及存取金鑰、請求和回應，以及用量、額度、錯誤、耗時等執行記錄。請求可能包含你或接入閘道的用戶端提供的個人資訊、提示詞、圖片、音訊、檔案等內容。請勿提交你無權提供的資訊。

## 儲存和保留期間

設定、憑證和記錄儲存在你選擇的資料庫及儲存位置。請求內容的記錄範圍和保留期間取決於日誌及保留設定。使用你設定的遠端資料庫或儲存服務時，資料不只存放在本機。應用程式會顯示憑證加密是否可用，請勿假設所有已儲存的憑證都已加密。請妥善保護裝置、資料庫、備份和金鑰。

## 網路傳輸及第三方

應用程式會將請求及必要的憑證傳送到你設定的供應商和服務位址；如果你選擇境外服務，資訊也會相應傳送至境外。供應商登入、模型列表、額度查詢、模型資源下載及遠端資料庫連線也會存取對應的服務。這些服務有各自的條款、保留規則和隱私權政策，請在了解並同意其處理方式後再設定使用。

應用程式預設使用系統字型。只有你在首次設定或設定頁中選擇下載介面字型後，GPROXY 才會依序嘗試從公開的 npm CDN（registry.npmmirror.com、cdn.jsdelivr.net、unpkg.com）下載，逐一以 SHA-256 驗證後儲存到本機，供離線使用。CDN 服務會收到下載裝置的 IP 位址和一般的 HTTP 請求資訊，不會收到閘道的提示詞或憑證。在你選擇下載之前不會下載字型。你可以在設定中刪除已下載的字型並恢復使用系統字型。從商店安裝的版本由該商店提供應用程式更新，並適用該商店的政策。GPROXY 不會自動向發布者傳送閘道資料，包括分析或支援用途。

## 權限用途

網路權限用於閘道及你設定的網路服務。Android 通知和前景服務權限用於顯示由你啟動或由你允許開機自動啟動的閘道的執行狀態，並提供停止入口。在 Android 上，可選的啟動和電池設定用於離開應用程式後繼續執行，可以在應用程式或系統設定中調整。HarmonyOS 的背景執行能力取決於裝置和實際授予的權限。商店版本不要求安裝下載 APK 的權限。

## 你的選擇和刪除方式

你可以選擇供應商、服務位址、儲存、用戶端、日誌及保留設定。監聽位址預設僅限本機；將監聽開放到網路會改變其他人存取執行個體的範圍。本機上的其他應用程式也能連線到本機監聽位址，但模型 API 請求仍需要閘道存取金鑰，請妥善保管金鑰。可以透過管理介面刪除支援刪除的帳號、憑證和記錄。刪除全部執行個體資料前請先停止閘道。清除 Android 應用程式儲存空間或解除安裝會移除應用程式的私有本機資料；匯出的檔案、備份、遠端資料庫及供應商持有的資料需另行刪除。HarmonyOS 應用程式資料可以透過系統的應用程式和儲存設定刪除；另行儲存的備份也需個別刪除。刪除本機資料不會刪除供應商持有的副本。你可以隨時停止使用、刪除應用程式資料並解除安裝。
