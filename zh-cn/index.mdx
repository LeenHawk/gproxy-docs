## 常用功能

<Columns cols={2}>
  <Card title="管理上游账户" icon="gear">
  在一个控制台管理 API Key、OAuth 和 Cookie 凭证，查看健康状态和上游额度。
</Card>
  <Card title="配置模型路由" icon="shuffle">
  为客户端设置固定的模型名，按权重分配请求，并配置备用供应商。
</Card>
  <Card title="连接不同协议" icon="puzzle-piece">
  支持 OpenAI、Claude 和 Gemini API 格式及流式响应，具体操作取决于渠道和上游能力。
</Card>
  <Card title="查看用量与费用" icon="file-lines">
  管理用户和密钥的访问权限与费用预算，查看请求记录和计费明细。
</Card>
</Columns>
