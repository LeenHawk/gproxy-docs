控制台是 GPROXY 的 Web 界面，个人使用和管理都在这里完成。本页介绍控制台各部分的功能，以及范围管理员如何使用它。

CLI 和容器版本在 `/console` 提供控制台。使用部署时配置的账号登录；控制台通过 `/portal/api/login` 登录，会话保存在 HttpOnly Cookie 中。

## 首次启动

CLI 和容器实例在首次启动时创建管理员，在浏览器中打开 `/console/` 用该账号登录即可，不会显示设置向导。

全新的 Application 实例则会在进入应用内控制台之前显示设置向导，步骤依次为“实例设置”“管理员账户”“上游渠道”；登录后，在“添加凭据”中为刚创建的供应商添加凭证。详细步骤见[下载与安装](/zh-cn/download#setup)。

## 语言

控制台提供英语、简体中文、繁体中文和俄语（Русский）界面。首次使用时，控制台从浏览器或系统设置中选择一种支持的语言；`ru-RU` 等俄语地区标签统一使用俄文界面。手动选择的语言优先，并保存在当前设备上。数字和日期按所选语言格式显示，金额仍使用配置的计费币种。

## 管理范围

控制台把 `/portal/api/context` 提供的个人页面，与 `/admin/api/context` 返回的管理功能合在一起。能看到哪些内容取决于角色：

- 实例管理员管理整个网关。
- 组织和团队管理员通过同一个“供应商”入口管理自己范围内的凭证。他们的“组织”“团队”页面只显示有权访问的对象及其费用预算，不能增删改身份，也不能修改供应商配置。

如果你管理多个组织或团队，在账户菜单中选择管理范围。之后的管理请求会在 `x-gproxy-admin-scope` 头中携带后端提供的范围标识。切换范围会关闭正在打开的编辑窗口和登录流程，并替换该范围的缓存数据；正在提交的写入需要完成后才能切换。个人页面不受管理范围影响。

个人费用预算在“概览”中与用量一起只读显示，没有单独的个人配额页。预算由管理员在对应的用户、API Key、组织或团队上设置。

## 页面

配置相关页面及其菜单名称：

| 控制台路径 | 菜单名称 | 内容 |
| --- | --- | --- |
| `/console/providers` | 供应商 | 供应商配置、凭证、模型、协议转换、重写规则绑定、端点覆盖 |
| `/console/model-routes` | 模型路由 | 跨供应商路由、成员、权重、回退层级和对外模型名 |
| `/console/rule-sets` | 规则集 | 重写规则、排序以及整组保存 |
| `/console/model-catalog` | 模型 | 全局模型目录和全局价格 |
| `/console/settings` | 全局设置 | 实例与日志设置 |
| `/console/settings/transfer` | 配置导入导出（“全局设置”中的标签） | 配置导出与导入；`/console/transfer` 打开同一面板 |
| `/console/clients` | HTTP 客户端配置 | 可复用的连接配置 |
| `/console/tokenizer` | 词表管理 | 词表下载和模型词表绑定 |
| `/console/update` | 系统更新 | 当前宿主支持的更新操作 |

供应商页面有“凭证”“模型”“规则”“路由规则”“设置”几个标签。“路由规则”管理该供应商的操作与协议转换；“模型路由”负责在多个上游供应商之间选择。两者分别配置。

配置表格支持勾选当前页的记录并批量删除；带启用开关的记录还可以批量启用和停用。修改筛选条件、翻页或切换管理范围都会清空已选记录。每次批量操作都通过现有的事务性配置 API 完成。

## 凭证与上游登录

供应商的凭证在其“凭证”标签中管理，在这里新建的凭证和发起的登录流程都归属该供应商。可选的归属对象限于当前管理范围。租户目录只显示供应商名称和可用操作，不显示网关配置。

编辑凭证会打开一个面板，包含“基本设置”“本地限额”“上游额度”三个标签。在凭证行上也可以直接打开“上游额度”、测试或删除凭证。

- 查看和刷新密钥的按钮在“基本设置”的密钥字段下方。
- 修改状态和“重置健康状态”在状态区域。
- 测试弹窗会读取可用模型，并分别显示结果、耗时和回复。“测试生成”会真实请求上游。
- 上游额度以金额、次数和重置时间显示。

### 登录上游

“登录添加凭证”会列出该渠道支持的登录方式。

浏览器授权的步骤：

1. 点击“开始登录”，打开授权链接。
2. 在上游完成授权。
3. 复制包含 `code` 和 `state` 的完整回调 URL，粘贴到控制台中。如果回调地址是已注册的本机地址，浏览器中的页面可能打不开，此时照样从地址栏复制回调地址即可。控制台不会启动本机回调监听服务。
4. 点击“完成登录”。

设备码方式：打开验证链接，输入控制台显示的验证码。控制台按后端返回的间隔轮询，在成功、拒绝、过期或关闭窗口后停止。

登录会话绑定发起登录的用户、管理范围和凭证归属。完成后只返回凭证 ID，不返回密钥。关闭未完成的流程只会停止界面操作，后端缓存的会话会自行过期。刷新页面不会恢复登录向导。

上游登录接口都是 `/admin/api/credential-login` 下的 POST 请求：`/authcode/start`、`/authcode/complete`、`/device/start` 和 `/device/poll`，沿用凭证管理的范围检查。按凭证发现和测试模型分别使用 `/admin/api/credentials/{id}/models/discover` 和 `/models/test`。

## 配额与价格

### 密钥预算

管理员在“个人 → 我的密钥”和“访问控制 → 用户密钥”中新建密钥时，可以在名称下方直接勾选“设置此密钥的费用预算”，填写金额和周期。密钥与初始预算在同一事务中保存，预算校验失败时不会创建密钥。编辑已有密钥会打开一个面板，包含“基本设置”和“费用预算”两个标签。

普通用户照常自助创建和管理自己的密钥，费用预算只能由管理员设置。

### 费用预算

用户、API Key、组织和团队上都有“费用预算”入口，规则的新增和编辑都在该面板内完成，不再弹出第二层窗口。费用以 USD 十进制字符串表示。供应商和凭证上的请求次数限额使用 `count` 单位。

### 默认凭证限额

供应商的“设置 → 默认凭证限额”中的每条规则分别作用于每个凭证，而不是整个供应商共享的预算。这里只显示配置，实际用量和重置时间在各个凭证中查看。

凭证上已启用的同名规则会覆盖供应商默认规则。“恢复继承”会删除凭证上的这条单独设置。停用单独设置同样会让已启用的默认规则重新生效，并不表示取消限额。

凭证限额卡片显示规则来源、上限、实际用量和下次重置时间。组织和团队管理员可以查看生效的限额，由实例管理员配置。周期、金额或次数、模型匹配和启用状态都可以直接在卡片上修改；自定义时长和固定周期的起点在高级选项中。

### 重置限额

重置供应商默认规则会影响当前继承它的所有凭证，确认提示会写明影响范围。继承来的卡片没有单独的重置按钮。重置凭证单独规则或调用方预算时，只重置那一条规则。以上操作都不会重置上游账号的额度。

### 价格

全局价格在“模型”页编辑，供应商专属价格在供应商的“模型”标签中编辑。模型弹窗同时管理价格规则、按维度区分的费率以及上下文档位和服务档位。

价格规则可以作用于全部供应商或某一个供应商，模型匹配支持 `*` 和 `?`。同一个模型可以有多条按操作区分的规则。价格的计算方式见[价格与分层](/zh-cn/reference/pricing)。

## 导入导出

导入导出文档包含网关配置，不包含身份、用量和请求日志。

- “导出配置”默认不含凭证密钥，勾选“包含已存储的凭证密钥”后才会导出，导出的是已存储的加密格式。
- “导入配置”接受当前的 v4 文档格式。选择文件后显示的摘要列出格式版本和记录数量，这不是后端预检的结果。

导入模式决定已有记录如何处理：

- “合并”更新 ID 相同的记录，保留文件中未提及的记录。
- “替换配置”还会删除文件中未提及的记录，范围限于可导出的配置类别。

来自另一个主密钥的加密密钥，需要在“源主密钥（可选，Hex 或 Base64）”中填写源实例的主密钥，后端才能重新加密。不填写时，目标实例必须使用相同的主密钥。提交后界面会清空该字段。

导入在一个事务中完成，提交后宿主会重新加载运行时设置。请查看返回的警告和跳过数量。如果重新加载失败，结果会显示配置已经导入，并附带一条运行时警告；数据库写入并没有回滚。

## 字体

CLI 和 Application 版本的控制台默认使用系统字体。可以在应用首次设置时，或之后在设置中的“界面字体”处点击“下载界面字体”，下载 Noto Sans、Noto Sans SC/TC 和 Noto Sans Mono。GPROXY 会依次尝试从公共 npm CDN（npmmirror、jsDelivr、unpkg）下载约 9.2 MiB 字体。每个文件都以自己的 SHA-256 命名，哈希不符就不接受，因此不需要信任 CDN。字体保存在本地数据目录中，离线也能使用。在选择下载之前，不会发出任何字体请求。点击“删除字体并使用系统字体”即可恢复系统字体。

Edge 部署把字体作为同源静态资源提供。headless 包既不含控制台，也不含字体。

v4.1.14 及更早的版本从 `https://gproxy.leenhawk.com/fonts/` 下载字体，文档站已不再提供这些文件，所以在这些版本上下载会失败，控制台继续使用系统字体。升级后即可恢复。

## 构建控制台

依次运行 `pnpm --dir console lint`、`pnpm --dir console test` 和 `pnpm --dir console build`。构建会做类型检查、用 Vite 打包，并把资源复制到控制台的嵌入目录。之后构建的原生程序会在 `/console` 提供这些资源；Edge 部署则把同一份资源作为网关前的静态资源提供。见[构建](/zh-cn/development/building)。
