本参考从 Rust 协议类型、管理 DTO 和宿主路由声明生成，请求与响应分别使用各自的 Serde 规则。每个端点在左侧栏「HTTP API」分组下都有单独的页面，按 Forwarding、Management、Portal、OAuth 和 System 分组，列出参数、请求体、状态码以及引用的数据结构。

共用的转发路径根据请求头选择协议，`stream: true` 切换为流式操作。SSE 结构描述解码后的单个事件，WebSocket 结构描述升级连接后的消息；二进制和 multipart 载荷保留各自的内容类型。

转发路径也可使用供应商或命名空间前缀。Codex 专用路径要求指定 Codex 供应商名称。挂载、鉴权及管理权限范围见[路由与端点](/zh-cn/reference/routing-table)。

完整规范可下载 [OpenAPI JSON](/generated/openapi.json)，导入 Postman、Insomnia 或代码生成工具使用。
