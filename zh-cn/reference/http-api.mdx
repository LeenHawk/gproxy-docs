本参考说明每个 HTTP 端点的参数、请求体、响应及其引用的数据结构，内容从 Rust 协议类型、管理 DTO 和宿主路由声明生成，请求与响应结构遵循各自的 Serde 定义。每个端点在侧栏「HTTP API」分组下都有单独的页面，按 Forwarding、Codex provider、Management、Portal、OAuth 和 System 分类。

共用的转发路径根据请求头选择协议，`stream: true` 切换为流式操作。SSE 结构描述解码后的单个事件，WebSocket 结构描述升级连接后收发的消息；二进制和 multipart 载荷保留各自的内容类型。

转发路径也可以加上供应商或命名空间前缀，Codex 专用路径需要使用 Codex 供应商的名称。挂载点、认证和管理权限范围见[路由与端点](/zh-cn/reference/routing-table)。

完整规范可下载 [OpenAPI JSON](/generated/openapi.json)，导入 Postman、Insomnia 或代码生成工具使用。
