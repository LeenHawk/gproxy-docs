This catalogue lists each channel's capabilities, login modes, configuration
keys and vendor service routes. It is generated by calling every compiled
channel's `descriptor()` and reading its service-route declarations, and it
covers all channels in the SDK's `channels` feature group. A particular binary
may be built with fewer.

A capability means the channel implements that optional interface. It does not
mean a given account has access, and it is not a matrix of supported protocol
operations. Configuration placeholders are examples, not runtime defaults.

Vendor service routes are reachable only on a provider or namespace mount, and
access also depends on the caller's role and the requested service view. Each
route's classification shows whether it is restricted or refused. To set up a
provider for a channel, see [Providers & Credentials](/guides/providers).
