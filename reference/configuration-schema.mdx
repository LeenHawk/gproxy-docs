This page lists every field of the configuration document: its type, its
variants and its default. It is generated from the Rust `AppConfig` type and
its nested types with `schemars`, so field names are the Serde names and
defaults are the Rust defaults. The native binary, the Workers host and the
desktop application all read this same structure.

For command-line flags, environment variables and which source wins, see
[Configuration](/reference/configuration).

The schema describes the structure only. Some checks happen at startup and are
not expressed here, for example that a master key decodes to exactly 32 bytes
or that the selected database backend was compiled into the binary.
